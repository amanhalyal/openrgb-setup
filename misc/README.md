# Historical scripts

Files in this directory are preserved investigation snapshots. They predate
the serialized SDK adapter, contain machine-specific absolute paths, and may
trigger the ENE mode/color race documented in
[`../docs/ene-dram-apply-race-20260914.md`](../docs/ene-dram-apply-race-20260914.md).

Do not install or execute them. They are retained only to explain the history
and make regressions easier to compare.
